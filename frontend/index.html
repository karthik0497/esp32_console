📌 5. ESP32 Pin Definitions & Safe Hardware Pinout Guide

Developer Reference
🟢 Safe User GPIOs Recommended

GPIO 4, 13, 14, 16, 17, 18, 19, 21, 22, 23, 25, 26, 27, 32, 33
Fully safe for relays, LEDs, buttons, servos, PWM, and external sensors.

⚡ Default Sensor Busses I2C / SPI

Default I2C Bus: SCL = Pin 22, SDA = Pin 21
Default SPI Bus: MOSI = 23, MISO = 19, SCK = 18, CS = 5
DAC Analog Out: Pin 25, Pin 26 (True 8-bit DAC)

🟡 Input-Only Pins No Output/Pullup

GPIO 34, 35, 36 (VP), 39 (VN)
Can ONLY read inputs/ADC. They lack internal pull-up / pull-down resistors and cannot drive outputs.

🔴 Strapping & Caution Boot Critical

GPIO 0: Bootloader switch (must stay HIGH on boot)
GPIO 2: Built-in LED (must stay LOW during flash)
GPIO 6–11: Integrated SPI Flash (NEVER USE!)
